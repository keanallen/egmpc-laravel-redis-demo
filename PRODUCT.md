# Attendance Lab
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Laravel 12, Blade, MySQL, and Laravel's explicit Redis cache store.

## Users
Junior developers following a trainer's live caching walkthrough.

## Product Purpose
Compare a paginated attendance report from MySQL with the same data from Redis, then demonstrate stale results and targeted invalidation.

## Capabilities and Constraints
A standalone database; six branches, 3,000 synthetic employees and 60,000 explicit attendance records. All report cache operations ship commented out. Simple UI, readable application code, no artificial delays.

## Brand Commitments
Keep the UI simple. No external assets or frontend build required.
